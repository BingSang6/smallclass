# 小课堂 (smallclass)

给孩子在 iPad 上独立使用的学习闯关 Web App：数学口算 + 语文字词 + 单元巩固 + 今日复习。
纯静态、零依赖、离线可用（PWA），数据全部保存在设备本地（localStorage），无服务器、无账号、无隐私风险。

> 进度文档见 [ROADMAP.md](ROADMAP.md)（每个版本同步更新）。

## 功能

- **学科大厅（两层主页）**：选学科（数学·口算 🦁 / 语文·字词 📖）→ 进学科主页闯关
- **1~6 年级可选**：家长首次设置孩子姓名 + 年级，可建多个学生独立进度（各学科进度分开存）
- **每年级 6 个段位**（青铜→白银→黄金→铂金→钻石→王者），每段 3 星（对 4 题得 1 星、对 5 题得 2 星，集满 3 星升段）；本段 1 星即解锁下段；白银以上开放「⏱ 挑战模式」（每题 10 秒倒计时 + ⚡神速奖励）
- **语文·字词**：会认字/易错字 → 形近字 → 多音字 → 词语搭配 → 近反义词 → 成语运用，6 段闯关（426 题）
- **📚 单元巩固**：跟课本单元走的概念题 + 易错辨析题（目前内置北师大版四上 8 个单元 85 题，其他年级待录库）
- **🌅 今日复习（间隔重复）**：错题按 SM-2 简化调度（1/3/7/14/30 天记忆盒子），答对升盒、答错回盒底、升出第 5 盒 = 精通出池；跨学科混合，每次最多 8 题
- **📜 古诗·背诵**：53 首公版必背诗词、476 题（接下句/接上句/认作者/名句出处），按学段分年级分 6 段位
- **📅 每日任务 + 打卡**：复习一次/闯一关/答对 10 题三盏灯，完成得 🪙 金币；连续打卡 🔥（断了不清零只鼓励）
- **🐣 宠物养成**：金币喂食，🥚→🦄 七阶段进化（每天限 3 次）
- **⚔️ 人机 PK**：10 题竞速对战机器人（🐢/🤖/⚡ 三档速度），赢金币、解锁更快对手
- **🔀 混合挑战**：数学+字词+古诗四科混出 10 题交错练习（研究显示交错优于分块刷题）
- **错题重现**：答错立即提示错因，当场再练一道同类题（口算换数字 / 概念题重问），并自动排入明日复习
- **零打字**：大按钮点选答题，选项乱序，即时反馈
- **语音读题**：自动朗读题目（可开关），还不会认字也能玩；分数按中文读法（"三分之二"）
- **贴纸奖励**：过关得星和贴纸，收藏册可查看
- **休息提醒**：连续学习 20 分钟自动提醒休息眼睛
- **导出错题本**：家长设置里导出 markdown（含错题、错因、知识点分布），发给 AI 助教（primary-tutor-skill 环境）可针对性讲解、生成打印卷

## 部署（GitHub Pages）

1. Fork / push 本仓库到你的 GitHub
2. 仓库 Settings → Pages → Source 选 `main` 分支 `/root`
3. 等一分钟，访问 `https://<用户名>.github.io/smallclass/`

## iPad 使用（家长一次性设置）

1. 用 **Safari** 打开上面网址
2. 点 Safari 分享按钮 → **添加到主屏幕**
3. 孩子点桌面图标即可全屏使用，离线也能玩（更新后重开 App 即可）

## 本地开发 / 重新生成题库

```bash
# 本地预览
python -m http.server 8000   # 然后访问 http://localhost:8000

# 端到端测试（需 playwright + 本地 8765 端口服务）
python tools/test_app.py

# 重新生成题库
python tools/gen_bank.py        # data/banks/math-oral.json（1015 题）
python tools/gen_words.py       # data/banks/chinese-words.json（426 题）
python tools/gen_unit_bank.py   # data/banks/math-g4-units.json（四上 8 单元 85 题）
python tools/gen_poems.py       # data/banks/poems.json（古诗 476 题）
```

题库结构：`{q, a, options[2-3], wrongReasons[2], grade, level, tag, id, speak?}`，
陷阱选项按常见错误模式生成（漏进位差 1、口诀串记、退位忘减 1、小数点错位等）。

**改动 JS/CSS/题库后记得改 `sw.js` 里的 CACHE 版本号**，否则客户端继续用旧缓存。

**单元题库维护**：题源是 primary-tutor-skill 的知识库（单元/知识点/易错点）——改知识库 → 重跑 `gen_unit_bank.py` → SW 版本+1 即更新。只收知识点本身（法则/概念/口诀为公共知识），教材原文与学生档案不进公开仓库。
