# 小课堂 · 口算闯关 (smallclass)

给孩子在 iPad 上独立使用的口算练习 Web App。纯静态、零依赖、离线可用（PWA），
数据全部保存在设备本地（localStorage），无服务器、无账号、无隐私风险。

## 功能

- **1~6 年级可选**：家长首次设置孩子姓名 + 年级，可建多个学生独立进度
- **每年级 4 个段位**（青铜→白银→黄金→王者），由易到难，难度上限覆盖该年级课标：
  玩法：每关 5 题，全对过关，连续通关自动升段
- **零打字**：大按钮点选答题，选项乱序，选对选错都有即时反馈
- **语音读题**：自动朗读题目（可开关），还不会认字也能玩
- **错题重现**：答错立即提示错因，并当场换数字再练一道同类题；错题进入待巩固池，下次优先出
- **贴纸奖励**：过关得星和贴纸，收藏册可查看
- **休息提醒**：连续学习 20 分钟自动提醒休息眼睛

## 年级 × 段位范围

| 年级 | 青铜 | 白银 | 黄金 | 王者 |
|------|------|------|------|------|
| 1 | 10以内加减 | 20以内进退位 | 50以内加减 | 100以内加减 |
| 2 | 100以内加减 | 表内乘法 | 表内除法 | 乘除混合 |
| 3 | 两位数加减 | 口算乘法 | 口算除法 | 混合与估算 |
| 4 | 大数口算 | 整十乘除 | 乘法估算 | 简算凑整 |
| 5 | 小数加减 | 小数乘除 | 简便运算 | 混合口算 |
| 6 | 分数加减 | 分数乘除 | 三数互化 | 混合口算 |

## 部署（GitHub Pages）

1. Fork / push 本仓库到你的 GitHub
2. 仓库 Settings → Pages → Source 选 `main` 分支 `/root`
3. 等一分钟，访问 `https://<用户名>.github.io/smallclass/`

## iPad 使用（家长一次性设置）

1. 用 **Safari** 打开上面网址
2. 点 Safari 分享按钮 → **添加到主屏幕**
3. 孩子点桌面图标即可全屏使用，离线也能玩

## 本地开发 / 重新生成题库

```bash
# 本地预览
python -m http.server 8000   # 然后访问 http://localhost:8000

# 重新生成题库（data/banks/math-oral.json，683 题）
python tools/gen_bank.py
```

题库结构：`{q, a, options[3], wrongReasons[2], grade, level, tag, id}`，
陷阱选项按常见错误模式生成（漏进位差 1、口诀串记、退位忘减 1、小数点错位等）。
